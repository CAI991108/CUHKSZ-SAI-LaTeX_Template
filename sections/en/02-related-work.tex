\section{Related Work}
\label{sec:related}

Human--computer interaction research provides general principles for designing human--AI
systems: make system behaviour understandable, keep the user in control, and offer
actionable explanations when the system is uncertain \cite{amershi2019}. Work on model
documentation argues that a model's capabilities, training data, intended use and
limitations should be recorded so that reviewers can judge it \cite{mitchell2019,gebru2021}.

Our work is complementary. The guidelines say what a reviewer should be able to see; model
documentation says what should be recorded. We focus on putting both into a concrete review
workflow: every label carries evidence, every override records a reason, and the evaluation
reports failures as well as successes. Classification accuracy is not our only target, and
we do not assume that reviewers will trust the model unconditionally.
